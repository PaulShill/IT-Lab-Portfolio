Python Security Automation

Project Overview

This project was completed alongside the Google Cybersecurity Professional Certificate – Course 7: Automate Cybersecurity Tasks with Python.



The purpose was to develop fundamental Python programming skills and apply them to practical cybersecurity tasks involving authentication logs, user account information and IP address access lists.



Environment

Operating System: Windows 11

Programming Language: Python 3

Code Editor: Notepad

Command Line: PowerShell

Version Control: GitHub

4\. IP Allow List Automation

Completed a practical security automation exercise using Python.



The script:



Reads an existing IP address allow list.

Reads a separate list of IP addresses to remove.

Converts file contents into Python lists.

Iterates through the removal list.

Identifies and removes matching IP addresses.

Writes the updated allow list back to the original file.
