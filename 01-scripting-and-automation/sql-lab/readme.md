# Lab: Relational Database Querying & SQL Analysis (SQLite)

Spent some time working through a hands-on database lab on my Ubuntu machine, focusing on data modeling, CSV imports, relational joins, and database auditing with SQLite3.

## What I Used
* **OS:** Ubuntu Linux
* **Tools:** `sqlite3`, `script`, `cat`, `nano`, `git`
* **Files:** `cosmere_books.csv`, `cosmere_series.csv`, `cosmere.db`, `lab-session.txt`

## What I Did
1. **Environment Setup:** Started a terminal recording session with `script` and prepped the raw data files.
2. **Data Modeling & Imports:** Set up the database tables, got the schemas sorted with the right data types, and imported the CSV data into SQLite3.
3. **Running Queries:** Worked through filtering, sorting, and pattern matching using `LIKE`, logical operators, aggregate functions (`COUNT`, `AVG`, `SUM`), and grouping.
4. **Joins & Subqueries:** Tied related tables together via primary and foreign keys and wrote nested subqueries to pull specific subsets of data.

## Why This Matters
* **Auditing & Data Work:** Being able to query relational data directly is key for reviewing system logs, access records, and inventory databases.
* **Database Fundamentals:** Getting hands-on with schemas, data types, and CSV import pipelines builds a solid foundation for working with production systems like PostgreSQL, MySQL, and SQL Server.
