\# Basic PowerShell Scripting Practice



Completed a series of practical exercises to develop an understanding of PowerShell scripting as part of my CompTIA A+ studies. The aim was to become familiar with PowerShell syntax and understand how scripts can be used to automate basic IT support tasks.



\## What I Used



\- Windows 11

\- Windows PowerShell

\- Visual Studio Code

\- GitHub



\## What I Covered



\- Variables and data types (strings, integers, floats and Booleans)

\- Arrays and storing multiple values

\- Conditional statements using `if`, `elseif` and `else`

\- Comparison operators

\- `for`, `while` and `do-while` loops

\- Functions and parameters

\- Returning values from functions

\- Displaying information using `Write-Host`



\## Practical Exercises



\### 1. DeviceChecker.ps1



Created a basic device checker to practise working with variables, storage checks, arrays, loops and reusable functions.



\### 2. HelpdeskDiagnostic.ps1



Built on the first exercise by creating a workstation health checker. This included storage assessments, restart checks and a function to generate a basic workstation health report.



\## What I Learned



These exercises helped me understand how PowerShell scripts are structured, how variables and conditions work, and how loops and functions can be used to reduce repetitive tasks.



This provides a foundation for using PowerShell in IT support and system administration.



\## Files Included



\- `DeviceChecker.ps1` – Basic device checking exercises.

\- `HelpdeskDiagnostic.ps1` – Workstation diagnostic and health report exercise.
